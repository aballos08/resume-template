# Resume Template

A retro terminal-style resume/CV webpage built with React, Vite, TypeScript, and Tailwind CSS 4.

## Features

- Terminal-aesthetic dark theme with phosphor-green accents and IBM Plex Mono font
- Typewriter animation on name reveal
- CRT scanline overlay effect
- 3 tabs:
  - **Resume** — Experience, Education, Skills, and Recognition
  - **GitHub** — Stats bar + pinned repository cards with language colors, star/fork counts
  - **Community** — Memberships with handles, karma, and join dates
- Smooth tab transitions with Motion (Framer Motion)
- Fully responsive (mobile-first)

## Stack

- [React 19](https://react.dev)
- [Vite](https://vitejs.dev)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Motion](https://motion.dev)
- [Lucide React](https://lucide.dev)
- IBM Plex Mono & IBM Plex Sans (Google Fonts)

## Customisation

All content is at the top of `src/pages/Index.tsx`.
Edit the `profile`, `experience`, `education`, `skills`, `repos`, and `communities` arrays to make it yours.

## Getting Started

```bash
npm install
npm run dev
```
